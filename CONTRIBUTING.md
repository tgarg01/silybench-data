# Contributing

## Benchmark runs (`runs/`)
Submit only with `gpubench submit` from a clean checkout of
[silybench-bench](https://github.com/tgarg01/silybench-bench). Don't hand-edit `result.json`.

CI (`dataset check`) rejects: sample or smoke data, unfinished runs, unknown provider, dirty or
missing bench commits, extra files, and `raw.tar.gz` over 20 MB. Reviewers also check:
1. `hardware.gpu_type` and `price_per_hour_usd` look right for the named provider.
2. The numbers are plausible next to existing runs of the same GPU (the PR body has a capacity table).
   Big deviations need an explanation (driver, runtime, noisy neighbour, thermal throttling).
3. `raw.tar.gz` contains the per-repeat bench JSON that backs `result.json`.

On merge, CI rebuilds `derived/` and the website redeploys.

## Prices (`prices/`)
- `gpu_hourly.yaml`: public list prices only (no private quotes). One row per provider × GPU ×
  product, per GPU-hour. Always give `source` (the pricing page) and `checked_at`. Keep old rows
  out: update the row in place (git history keeps the old price).
- API prices: add providers OpenRouter doesn't carry to `api_manual.yaml`. The same model only;
  size-tier prices need a `notes` line. `api.yaml` is generated by
  `uv run --with pyyaml --with httpx scripts/update_api_prices.py`.
